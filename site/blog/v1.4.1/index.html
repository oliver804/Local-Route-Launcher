Intel Mac，也有对应安装包了

Local Route Launcher 现提供独立的 Intel Mac（x86_64）DMG，继续保留 Apple Silicon 和 Windows 安装包。在兼容的目标应用中，分别管理 ChatGPT、Antigravity App 和 Antigravity IDE 的启动配置。

选择适合你的 Mac 的版本

打开苹果菜单 →「关于本机」。显示 Apple M 系列芯片，选择 Apple Silicon；显示 Intel 处理器，选择 Intel。两个版本均要求 macOS 13 或更新系统。

Intel 安装包只解决启动器本身的架构兼容性。目标应用也必须提供可运行的 Intel 或 Universal 版本；仅支持 Apple Silicon 的应用不会因此变得兼容。

使用方式保持一致

选择目标应用，保存有权使用的 HTTP 代理地址、端口和安装路径，完全退出目标应用后再通过启动器启动。各应用独立保存配置，不修改系统代理或 DNS。语言、外观、菜单栏操作与连接检查保持一致。

启动器的更新入口会选择与当前构建架构匹配的安装包；Intel 版不会误下载 arm64 DMG。连接检查是即时快照，不代表全部流量、账号权限或模型服务已验证。
