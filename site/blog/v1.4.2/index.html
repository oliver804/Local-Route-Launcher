LOCAL ROUTE LAUNCHER · 1.4.2

Windows 10 21H2，也能安装启动器了

Local Route Launcher 1.4.2 将 Windows x64 安装门槛调整为 Windows 10 1809。ChatGPT、Antigravity App 与 Antigravity IDE 继续分别保存启动配置。

修复了什么？

此前安装包要求 Windows 10 22H2，21H2 会在运行应用之前被拒绝。现在最低版本调整为 build 17763（1809），包含 21H2、22H2 及对应 LTSC，Windows 11 继续保留。界面与代理启动机制保持不变。

兼容范围与验证边界

安装、隔离应用启动与连接、界面、托盘和卸载自动测试运行在 Windows Server 2022 / 2025，不能替代各 Windows 10 客户端版本的实机验收。仅提供 x64 安装包，暂不覆盖更早的 Windows 10、32 位 Windows 或 ARM64。

ChatGPT 与 Antigravity 自身也必须支持当前系统，启动器不会修改目标应用或绕过它们的系统要求。查看兼容性与验证范围。

下载安装与升级

从托盘退出启动器，运行新版安装包并安装到原位置，即可保留已有设置，无需另装 .NET。保持有权使用的本地代理运行，再从启动器打开兼容的目标应用。
