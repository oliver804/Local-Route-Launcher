LOCAL ROUTE LAUNCHER · 1.4.1

A dedicated download for Intel Macs

Local Route Launcher now offers an Intel Mac (x86_64) DMG alongside Apple Silicon and Windows installers. Manage separate launch settings for compatible installations of ChatGPT, Antigravity App and Antigravity IDE.

Choose your Mac download

Open the Apple menu → About This Mac. Choose Apple Silicon for an Apple M-series chip, or Intel for an Intel processor. Both builds require macOS 13 or later.

The Intel installer makes the launcher compatible with Intel Macs. Your target app must also provide a working Intel or Universal build. An Apple-Silicon-only app does not become compatible through the launcher.

The same workflow

Select an app, save an authorized HTTP proxy host, port and installation path, then fully quit the target app before launching it here. Each profile is independent; system proxy and DNS settings remain unchanged. Language, appearance, menu-bar controls and connection checks work the same way.

The update badge selects an installer matching the launcher build architecture, so an Intel build will not download an arm64 DMG. Connection checks are snapshots, not proof of complete traffic routing, account permission or model access.
