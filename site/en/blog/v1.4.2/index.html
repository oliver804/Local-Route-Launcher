LOCAL ROUTE LAUNCHER · 1.4.2

Windows 10 21H2 can now install the launcher

Local Route Launcher 1.4.2 lowers the Windows x64 installer minimum to Windows 10 1809. Separate profiles for compatible ChatGPT, Antigravity App and Antigravity IDE builds work the same way.

What changed?

The previous installer required Windows 10 22H2 and rejected 21H2 before the app could start. The minimum is now build 17763 (1809), including 21H2, 22H2 and corresponding LTSC editions. Windows 11 remains eligible. The interface and proxy mechanisms are unchanged.

Compatibility has boundaries

Automated installation, isolated launch/connection, UI, tray and uninstall checks run on Windows Server 2022 and 2025. These results do not establish acceptance on each Windows 10 client version. Only x64 packages are provided; earlier Windows 10 versions, 32-bit Windows and ARM64 are outside this release's scope.

ChatGPT and Antigravity must themselves support your system. The launcher does not modify target apps or bypass their requirements. Read the compatibility and validation scope.

Download and upgrade

Quit the launcher from its tray, then run the new installer using the existing location. Settings are retained, and no separate .NET installation is required. Keep your authorized local proxy running and launch the selected compatible app from the launcher.
