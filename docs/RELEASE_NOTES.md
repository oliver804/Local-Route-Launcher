## Local Route Launcher 1.4.4 — App update checks

### 中文

- 检查 ChatGPT、Antigravity App 和 Antigravity IDE 的官方稳定版。确认有适用新版时，在主窗口版本号旁、菜单栏和托盘对应应用名称后显示“更新到”。
- 点击徽标打开官方更新渠道。没有适用新版、来源不可达或安装渠道无法确认时，隐藏徽标。
- 启动器自身的更新继续通过底部版本旁的入口处理。

### English

- Check official stable channels for ChatGPT, Antigravity App and Antigravity IDE. Confirmed updates appear beside the installed version in the main window and beside the app name in the menu bar and tray.
- Select the badge to open the official update channel. The badge stays hidden when a compatible newer version cannot be confirmed.
- The launcher’s own updates still appear beside its version in the footer.

**Platforms:** macOS 13+ on Apple Silicon / Intel; Windows x64 installer minimum remains Windows 10 1809. Windows Server 2022 / 2025 automated checks do not replace client OS acceptance. Target apps retain independent OS requirements. See [Windows compatibility](https://github.com/oliver804/Local-Route-Launcher/blob/main/docs/WINDOWS-COMPATIBILITY.en.md).

**Distribution:** macOS packages are ad-hoc signed, not notarized; Windows installers are unsigned. Verify release origin and SHA-256 hashes and retain system protections.
